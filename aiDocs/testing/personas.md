# HabitDx User Personas

**Date:** April 2026  
**Purpose:** Multi-persona pre-presentation testing  
**Method:** Psychologically realistic personas designed to stress-test different dimensions of the product

---

## Persona 1: Marcus Chen — The Optimization Junkie

| Dimension | Detail |
|-----------|--------|
| **Age** | 28 |
| **Occupation** | Software engineer at a mid-size startup |
| **Primary goal** | Build a consistent morning routine (exercise + meditation + journaling) |
| **Secondary motivations** | Career performance, mental clarity, proving self-discipline, quantified-self curiosity |
| **Personality** | Analytical, competitive with himself, data-driven, impatient with inefficiency |
| **Technical fluency** | Expert — notices console.logs, tests edge cases, inspects network requests |
| **Behavioral tendencies** | Starts strong with 5+ habits, burns out in 2-3 weeks, restarts. Overcomplicates systems. Uses 3 productivity apps simultaneously. |
| **Biases** | Optimization bias (perfect system = perfect habits), novelty bias, overconfidence |
| **Frustration triggers** | Slow AI responses, inability to customize, no data export, feeling patronized |
| **Success definition** | Clear trend data showing improvement over 30+ days |
| **Quick abandonment** | Can't edit individual habits, AI feels generic, runs out of features to explore |
| **Trust threshold** | Medium — gives AI a real shot but judges harshly on output quality |
| **Tone preference** | Direct, data-forward, no hand-holding |
| **Feedback style** | Detailed bug reports with reproduction steps |

**Why this persona matters:** Marcus stress-tests the app's depth and customization. If HabitDx can't satisfy a power user who's read the habit literature, it risks being dismissed as "another basic tracker." His inability to edit individual habits is a dealbreaker-level finding. He also represents the user who would be HabitDx's most vocal advocate IF impressed.

## Persona 2: Diane Okafor — The Exhausted Restarter

| Dimension | Detail |
|-----------|--------|
| **Age** | 41 |
| **Occupation** | Single mom, part-time nurse (shift work), two kids under 10 |
| **Primary goal** | Get consistent sleep and stop stress-eating after night shifts |
| **Secondary motivations** | Wants to feel like she's not failing at self-care, needs something that works around an unpredictable schedule |
| **Personality** | Warm, self-deprecating, genuinely wants to change but deeply skeptical of her own ability. Guilt-prone. |
| **Technical fluency** | Moderate — uses iPhone daily but doesn't explore settings. Would never long-press without being told. |
| **Behavioral tendencies** | Downloads habit apps every January, uses them 4-6 days, one bad shift derails everything. Has 8 unused habit apps. |
| **Biases** | Internalizes failure. All-or-nothing thinking. Negativity bias (focuses on misses over completions). |
| **Frustration triggers** | Guilt-triggering messages, onboarding longer than 3 minutes, being asked to describe failures in writing |
| **Success definition** | One habit that survives a week of night shifts without making her feel worse |
| **Quick abandonment** | App makes her feel bad about missing days, doesn't accommodate shift work |
| **Trust threshold** | Low — expects to abandon it, pleasantly surprised if it works |
| **Tone preference** | Gentle, encouraging, never judgmental |
| **Feedback style** | Would ghost the app silently |

**Why this persona matters:** Diane is the app's hardest test and most important user. She's exactly who the "failure-first" approach could help OR harm. If the Failure Profile language triggers shame instead of insight, the app actively hurts users like Diane. She also tests whether selecting "Shift work" in onboarding actually changes anything downstream.

## Persona 3: Professor Raj Krishnamurthy — The Skeptical Academic

| Dimension | Detail |
|-----------|--------|
| **Age** | 55 |
| **Occupation** | Psychology professor, studies motivation and self-regulation |
| **Primary goal** | None specifically — evaluating the app's behavioral science claims |
| **Secondary motivations** | Intellectually curious, might recommend to students |
| **Personality** | Rigorously analytical, allergic to pseudoscience, appreciates genuine Fogg/Clear references but catches misapplications |
| **Technical fluency** | Moderate — comfortable with apps but not interested in workarounds |
| **Behavioral tendencies** | Reads every word. Tests whether AI is truly personalized or templated. Compares outputs to research. |
| **Biases** | Academic rigor bias. Skeptical of AI hype. Compares claims to evidence base. |
| **Frustration triggers** | Overpromising, misusing behavioral science terms, "Your Superpower" framing |
| **Success definition** | App demonstrates genuine personalization and sound behavioral principles |
| **Quick abandonment** | Discovers AI gives similar profiles regardless of input |
| **Trust threshold** | Very high — needs the science to work, not just be referenced |
| **Tone preference** | Respectful, precise, no false enthusiasm |
| **Feedback style** | Detailed written critique with citations |

**Why this persona matters:** Raj is the evaluator at a demo. If HabitDx's behavioral science claims don't hold up under scrutiny, the value proposition collapses. He'll test whether the Failure Profile is actually diagnostic or just a personality quiz dressed up with AI.

## Persona 4: Gloria Reeves — The Reluctant Smartphone User

| Dimension | Detail |
|-----------|--------|
| **Age** | 67 |
| **Occupation** | Recently retired teacher, lives alone |
| **Primary goal** | Walk daily and drink more water — doctor's orders after pre-diabetes diagnosis |
| **Secondary motivations** | Wants structure now that work doesn't provide it, lonely, looking for small wins |
| **Personality** | Patient but easily confused by modern UI, reads everything carefully, embarrassed to ask for help |
| **Technical fluency** | Low — iPhone set up by daughter, uses it for calls/texts/Facebook. Never used Google OAuth. |
| **Behavioral tendencies** | Very conscientious once she understands what to do. Gives up if setup is confusing. Won't discover features on her own. |
| **Biases** | Assumes "AI" means the app is watching her. Privacy-anxious. |
| **Frustration triggers** | Small text, jargon, unclear next steps, anything that feels like a test she can fail, the word "failure" |
| **Success definition** | Daily walking tracked for 2 weeks, feels proud instead of nagged |
| **Quick abandonment** | Can't figure out signup, AI chat feels like talking to a stranger, "Failure Profile" sounds medical |
| **Trust threshold** | Very low for tech, high for authority figures |
| **Tone preference** | Warm, simple, reassuring |
| **Feedback style** | Would call her daughter and say "this app doesn't make sense" |

**Why this persona matters:** Gloria exposes every accessibility and jargon issue. She represents a huge untapped market (retirees building health habits) that the app's current mental model ignores. The "tap to complete" interaction is effectively invisible to her.

## Persona 5: Jordan Park — The Career Non-Fitter

| Dimension | Detail |
|-----------|--------|
| **Age** | 33 |
| **Occupation** | Product manager at a fintech company |
| **Primary goal** | Practice public speaking and build networking habit — career growth, not wellness |
| **Secondary motivations** | Just promoted, imposter syndrome, wants professional presence |
| **Personality** | Ambitious, impatient, pragmatic. Sees habits as career tools. Slightly cynical about self-help. |
| **Technical fluency** | High — evaluates apps like a PM, notices UX antipatterns |
| **Behavioral tendencies** | Forces the app to fit their use case. Frustrated when it can't. |
| **Biases** | Efficiency-oriented. Judges by first 60 seconds. ROI-driven. |
| **Frustration triggers** | Long onboarding for simple features, wellness-only framing, inability to add custom habits freely |
| **Success definition** | Tracks one professional development habit on their terms |
| **Quick abandonment** | Onboarding > 2 minutes, habit options are all wellness-focused |
| **Trust threshold** | Medium — willing if setup is fast, drops immediately if it wastes time |
| **Tone preference** | Professional, efficient, minimal cheerleading |
| **Feedback style** | Would tweet about what the app gets right and wrong |

**Why this persona matters:** Jordan exposes HabitDx's biggest mental model assumption: habits = wellness. The HABIT_OPTIONS list is entirely wellness-focused. The AI chat handles career goals well, but the form path and app framing don't match.

## Persona 6: Tyler Watts — The ADHD Procrastinator

| Dimension | Detail |
|-----------|--------|
| **Age** | 24 |
| **Occupation** | Freelance graphic designer, recently diagnosed ADHD |
| **Primary goal** | Stop doom-scrolling, start working on client projects before deadlines |
| **Secondary motivations** | Therapist suggested building structure, wants to prove he can be consistent |
| **Personality** | Creative, impulsive, deeply self-aware but struggles with executive function. Humor as coping. |
| **Technical fluency** | High — digital native, explores every feature |
| **Behavioral tendencies** | Hyperfocuses on setup (30 mins on onboarding), then forgets app for 3 days. Swipes away notifications. |
| **Biases** | "Planning is doing" trap. Novelty dopamine during setup, zero follow-through. |
| **Frustration triggers** | Binary pass/fail tracking (needs partial credit), streak breaks, accusatory warnings, long text-heavy screens |
| **Success definition** | Completing even a tiny version 3 days in a row |
| **Quick abandonment** | Streak breaks, feels like starting over, "Don't miss twice" feels accusatory |
| **Trust threshold** | Open to anything but expects to fail — stays if app handles failure gracefully |
| **Tone preference** | Authentic, slightly casual, zero guilt |
| **Feedback style** | Would tell his therapist about the experience |

**Why this persona matters:** Tyler represents a growing user segment (neurodivergent users seeking structure) and stress-tests the binary tracking model. ADHD users need partial credit, flexible scheduling, and zero-guilt design — the current "completed or missed" model is fundamentally hostile to executive dysfunction.
